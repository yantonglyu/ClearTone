# 澄音 ClearTone v0.2.0

这一版将播放页扩展为完整的个人播放器。主页、音乐库、跟唱和底部播放条共享同一个播放会话与专注计时器。

## 新增与改善

- 主页展示今日推荐、继续听和更多带封面的推荐歌单，适配较小窗口。
- 收藏支持添加顺序和歌手分组。新增独立歌手收藏，浏览歌手完整歌曲及网易云 MV 目录。
- B 站公开视频与网易云 MV 可进入同一个队列，音乐和视频之间平滑切换布局。
- 网络音频定位与视频取帧移到后台线程。连续拖动会合并请求，定位超时可恢复，避免网络等待阻塞整个窗口。
- 加强歌手主题的边缘星光与切歌动画，暂停或隐藏后停止持续动画。
- 搜索支持网易云、B 站和本地来源，包含歌曲与作者。统一三点菜单、分类设置和透明感界面。
- 连续跟唱、平假名与罗马音切换、注音纠错、逐字进度和变速不变调。
- 输出设备、WASAPI 共享/独占、EQ、ReplayGain、预放大和处理旁路。可选 DSD→PCM 兼容播放。
- 结束专注移到计时器旁，保留休息与累计学习记录。播放记录按实际收听时间上报，独立于学习记录。

## 安装

下载 `ClearTone-0.2.0-win-x64-Setup.exe`，正常关闭旧版后安装。适用于 Windows 10 2004 或更新版本、Windows 11 x64。安装器包含运行所需的 .NET、WinUI、Node 和 C++ 运行库，不需要开发工具。

安装包不附带开发者的账号、歌曲、播放历史或学习记录。升级保留个人数据。Python、分析模型和 FFmpeg 不属于基础安装包。

## 已知边界

第三方媒体可能受会员、地区、版权、编码和临时链接影响。单次测试不能保证所有 B 站视频和 MV 都可播放。音视频同步、驱动兼容性和长时间资源占用仍需更多设备验证。

BPM、节拍、拍号与人声音高都是估计，没有经标注数据集测得的准确率。逐字歌词优先使用平台时间戳，缺失时采用近似值。独占开关不等于 bit-perfect，当前不提供原生 DSD/DoP。

性能优化持续进行。流动背景、频谱、视频解码和可选人声分析都有成本。接下来优先做播放稳定性、资源回收和媒体通路隔离，再逐步扩展来源与跟唱能力，见 README 中的路线图。
