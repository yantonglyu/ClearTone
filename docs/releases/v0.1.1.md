# 澄音 ClearTone v0.1.1

这次更新补上网易云播放记录同步。播放器按实际音频输出累计收听时间，在换歌、播完或退出时提交。暂停、拖动跳过的片段、预加载和后台分析不计入，暂停后继续同一首歌仍算同一轮收听。

- 独立待发送文件保存已累计的时间，持久化账本防止重复提交。上报失败不阻塞正常播放。
- 经授权实测，最近播放、周排行和当日分钟统计有更新。总累计听歌时长接口未在短时复查中更新，不能承诺所有统计立即同步。
- 网易云接口没有已验证的幂等键，响应不明确或进程中断的外部请求不会自动重发，避免重复统计，可能漏记部分记录。
- README 更新同步说明、隐私边界和后续产品路线。多音源音乐库、搜索、视频、跟唱和 Hi-Fi 仍是规划，本安装包不含这些未来功能。

## 下载与安装

下载 `ClearTone-0.1.1-win-x64-Setup.exe`，先正常退出旧版，再安装。适用于 Windows 10 2004 或更新版本 / Windows 11 x64。已内置 .NET、WinUI、Node 和 C++ 运行库，可选 Python/模型不随包提供。

安装包从干净源码生成，不含开发者账号、Cookie、播放记录、歌单、学习记录、媒体缓存或模型。首次使用请登录自己的网易云账户。个人数据保存在用户数据目录，卸载保留数据。非安装器管理的便携目录应选择新的安装位置，不强制覆盖。

用 `SHA256SUMS.txt` 核对下载完整性。此安装包尚未代码签名。已知第三方依赖公告及影响范围见 [SECURITY.md](https://github.com/yantonglyu/ClearTone/blob/main/SECURITY.md)。

## 验证范围

已运行实际输出计时、暂停/拖动排除、账号隔离、持久化恢复、并发与重启去重、EQ、歌词和学习计时回归。实际网易云统计验证结果见上文，不把接口返回成功等同于全部统计更新。

安装器的隔离安装、启动、播放和数据保留结果见 [验证记录](https://github.com/yantonglyu/ClearTone/blob/main/docs/VALIDATION.md)。当前验证不覆盖全新 Windows 系统、所有音频设备或第三方服务的所有地区。
