# 澄音 · ClearTone v0.1.0

首个可直接安装的 Windows x64 公开版本。

## 下载与安装

下载 `ClearTone-0.1.0-win-x64-Setup.exe`，双击安装。支持 Windows 10 2004 或更新版本、Windows 11 x64。安装包约 112 MiB，安装后约 420 MiB。普通播放与计时不需要另外安装 .NET、Node 或开发工具。

奶白与浅粉的小猫安装界面，支持选择安装盘和可选桌面快捷方式。安装在当前用户下，无需管理员权限。

初次启动没有账号、歌单和学习记录，请登录自己的网易云账号。卸载保留本地学习记录。升级前请正常退出澄音，安装器不会强制结束播放或计时。

## 包含功能

- 网易云扫码登录、歌单与每日推荐、喜欢和收藏、多选加入播放队列。
- 沉浸歌词、拖动和点击跳转、翻译与罗马音开关。
- 封面配色背景、频谱、五段 EQ、采样率显示。
- 专注与休息计时，本地记录保存和导入导出。
- B站公开音频播放。没有歌词时使用居中布局。

## 请先了解

- **人声分离、BPM 和拍号模型需另行配置。** 安装包不含 Python、PyTorch 或模型权重，不会自动下载这些大型组件。配置方法见 README。
- **仍有资源与准确性限制。** 动画和模糊会使用 GPU/CPU，首次模型分析较重。BPM 可能出现半速、倍速或变速误判，拍号特别是分母不一定能从音频唯一确定。人声音高可能受分离残留、和声和滑音影响。尚未完成标注数据集准确率评测。
- **播放权限仍由平台决定。** 登录不保证完整播放，部分歌曲只能试听。第三方接口可能变化，不保证网易云听歌时长或排行同步。
- **安装包暂未代码签名。** 可能出现未知发布者提示。请从此仓库下载并核对 `SHA256SUMS.txt`，不要从不明镜像安装。
- **验证范围有限。** 已在 Windows 11 x64 上完成独立安装、空账号启动、合成音频播放、歌词、学习记录、升级和卸载测试。尚未完成全新 Windows 虚拟机验证或可选模型全新安装测试。已知依赖公告见 SECURITY.md。

安装包从源码和锁定依赖生成，不包含开发者的账号、Cookie、音乐缓存、学习记录或模型缓存。
