# 跟唱与音频通路更新

日期：2026-10-22。本次为本地 0.2 播放器预览更新，公开 Release 版本仍为 v0.1.1。

## 本次变化

跟唱页以约 220 ms 的原生合成交叉过渡衔接下一句。歌词的樱粉色覆盖层随音频位置推进，暂停保持原位，向前或向后跳转立即重新定位。歌词与平假名继续成组换行。动画只保留当前句和短暂离场句，不为全曲建立逐字视图，离页或最小化停止动画。遵循 Windows 动画设置。

网易云音源优先读取 YRC 的词级时间。仅在歌词文本与邻近时间匹配时采用它，允许标点的零时长边界、间隙和重叠词。缺失或版本不匹配时，按字符与读音音节估算进度。悬停歌词可辨认时间轴来源，不把 LRC 估算称为精确识别。YRC 的多字符词块内部仍以连续覆盖表示，不代表完成了逐音素声学对齐。接口依据来自[适配器维护方实现](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/main/module/lyric_new.js)，不是网易云公开的正式格式规范。

音乐库改为一个搜索面与收藏、队列、最近、歌单四个直接入口。来源和搜索类型收进同一搜索范围菜单，账号与添加入口固定在右侧。导入、打开 B 站链接与保存混合歌单集中管理。歌曲行继续使用三点菜单和虚拟化。长标题与播放操作使用独立布局列，避免互相覆盖。

声音设置增加以下能力，并将低频选项折叠：

- 预放大 -12 到 +12 dB。
- 本地 FLAC ReplayGain 曲目与专辑模式，默认关闭。读取已有 gain/peak 标签，无对应标签时 ReplayGain 应用 0 dB，独立预放大仍生效。不扫描整曲。标签格式依据 [FLAC 工具说明](https://xiph.org/flac/documentation_tools_metaflac.html#add_replay_gain)。
- 音色处理旁路，跳过 EQ、预放大与 ReplayGain。用户音量、峰值保护和跟唱变速仍按自己的设置生效，因此不叫原样输出或 bit-perfect。
- 采样峰值保护，保持原默认限幅行为，可关闭。标签峰值可用于预留增益余量，但不是真峰值检测或动态响度压缩。
- 区分原始本地格式、解码格式、输出流和设备共享混音格式。Media Foundation 优先请求 float 解码，不接受时回退。共享模式仍可能由 Windows 混音转换，详见 [NAudio WASAPI 文档](https://github.com/naudio/NAudio/blob/main/Docs/WasapiPlayer.md)。

DSF/DFF 使用现有 FFmpeg 转为 176.4 kHz / float32 PCM，作为兼容播放。原文件只读，缓存按路径、大小、修改时间与解码版本标识，限制总量约 1 GB，超出单文件限制拒绝不完整结果。后台转换使用较低进程优先级，切歌或退出会取消转换。正常 PCM 播放不启动 FFmpeg。可从安装目录的分析环境、`runtime/ffmpeg.exe` 或显式 `CLEARTONE_FFMPEG` 路径复用解码器，基础包没有附带 FFmpeg。容器验证依据 [FFmpeg DSF](https://github.com/FFmpeg/FFmpeg/blob/n7.1/libavformat/dsfdec.c) 与 [DSDIFF](https://github.com/FFmpeg/FFmpeg/blob/n7.1/libavformat/iff.c) 上游实现。

系统媒体控制接入 Windows 播放卡和媒体键。播放、暂停、上一首、下一首与进度请求回到原来的播放会话，不另建播放器或学习计时器。采用 [微软桌面互操作接口](https://learn.microsoft.com/windows/apps/desktop/modernize/winrt-com-interop-csharp) 和 [手动 SMTC 控制](https://learn.microsoft.com/windows/apps/develop/media-playback/system-media-transport-controls)。

## 备份与验证

编辑前已分别备份工作区源码和安装目录用户数据。安装时另备份完整应用与服务。没有把个人账号、播放历史或学习数据放入候选 bundle。

服务回归 26 项通过，覆盖完整歌单、来源搜索、播放记录去重、后台读音与 YRC。公开匿名 YRC 样本中，两首分别返回 45 行 / 392 词、47 行 / 394 词，第三首没有 YRC 时保持旧 LRC 兼容。

ReadingTests 通过精确时间、重叠、静音间隙、跳转、零时长标点、读音估算和 Unicode 字素测试。CoreTests 通过 EQ、旁路、增益、ReplayGain、异常标签、变速、学习和休息、原子保存及实际听时长测试。

真实共享输出静音测试覆盖播放、暂停、跳转、有效设备切换和失效设备回退，系统主音量未改变。保存失效设备与独占偏好后，连续两次加载均回退共享输出，不再在下一曲进入回退前失败。没有抢占独占设备制造冲突。

本地生成的 24-bit / 96 kHz FLAC 经 MF float 解码保留到最低有效位。合成 DSF、DFF 均转换为 176400 Hz / float32 / 双声道 / 2 秒，缓存重复使用、源文件不变与取消检查通过。合成样本只能验证这些格式和程序路径，不能代表所有商业 DSD 文件。

原生隔离实例通过精确逐字时间、暂停冻结、前后跳转、换句动效、退出循环后连续跟随、离页停止刷新和 LRC 估算回退。测试期间学习累计值保持不变。DSF/DFF 在原生应用内加载及缓存复用通过，Windows 媒体会话的实际播放/暂停请求通过。音乐库最终布局已分别在 948 × 634 和最大化窗口确认。

资源测量使用同一台 24 逻辑核机器、相同 948 × 634 窗口和 12 秒合成零音量音频。统计应用与其 Node 服务之和，播放状态各采样 30 秒，暂停与最小化各采样 15 秒。数据是短期样本，不能代表所有歌曲、驱动或后台分析负载。

| 状态 | 平均 CPU（全机百分比） | 平均专用内存 | 平均工作集 |
| --- | ---: | ---: | ---: |
| 原版跟唱，无逐字进度 | 0.659% | 321.5 MB | 417.4 MB |
| 最终跟唱，逐字进度与换句动效 | 0.910% | 310.8 MB | 406.9 MB |
| 新版暂停，窗口可见 | 0.245% | 305.9 MB | 400.7 MB |
| 新版暂停且最小化 | 0.017% | 307.7 MB | 406.2 MB |

最初使用持续 90 ms 合成动画的逐字高亮版本达到 1.302% CPU，未交付。最终方案复用现有约 10 Hz 播放 UI 时钟，只更新正在填充的词，不增加计时器，保留短暂的 220 ms 换句过渡。相比无高亮旧版仍有约 0.25 个百分点开销，不把功能增加描述成零开销。精确时间源与跳转等原生测试已在此最终版本重跑。

隔离回归验证播放、跟唱、计时与配置持久化。发行包不包含测试资料或个人数据。

## 仍未完成的能力

B 站视频已在后续版本加入，验证范围见音乐库与版本验证文档。无缝切歌、原生 DSD/DoP、ASIO、录音 A/B 和更多音源尚未实现。独占兼容性及真实 DSD DAC 仍需硬件验收。
